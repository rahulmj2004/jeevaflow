SAFETY BOUNDARIES

✕Never diagnoses, prescribes or changes medication; replies make no medical claims
✕Extracted values are never treated as verified until a person verifies them
✕Unanchored extractions are rejected, not stored
✕Conflicts are never silently resolved
✕Loops never auto-close: POTENTIAL_MATCH → CLOSED needs a named human
✕Unreadable images → RETAKE; nothing is read from them
✕Unknown WhatsApp numbers are never auto-registered
✕Twilio credentials only sent to https://*.twilio.com; secrets never logged
